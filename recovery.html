Recovery objective

Starting with a fresh computer, recover the encrypted NYX state from Google Drive, restore the infrastructure, restore persistent application data and AI memory, restore the preserved models, and validate the rebuilt system.

Fresh-machine recovery order

  1. Install a current Linux distribution.
  2. Create/use the primary account nyx with home directory /home/nyx.
  3. Install current versions of Git, rclone, Restic, Docker, Docker Compose, the NVIDIA driver, and NVIDIA Container Toolkit as appropriate for the new hardware and operating system.
  4. Obtain the NYX recovery credentials from KeePass.
  5. Configure rclone remote Nyx IntraLink using the saved Google OAuth client.
  6. Set the Restic repository to rclone:Nyx IntraLink:NYX-Disaster-Recovery/restic-v2.
  7. Open the existing repository with the saved Restic password.
  8. Run restic snapshots before modifying anything.
  9. Restore the newest valid NYX off-site snapshot to a temporary recovery directory.
  10. Locate and extract nyx-infra.tar.gz to /home/nyx/nyx-infra.
  11. Follow the recovered disaster-recovery documentation.
  12. Run the recovered bootstrap, restore, and validation scripts.

AI model preservation

The disaster-recovery system intentionally preserves exact critical model storage separately from routine backups.

Preserve/restore:

  • the complete V100 Ollama model store containing the exact Hephaestus / nyx-hephaestus-32k model
  • the complete P100 Ollama model store
  • bge-m3
  • nyx-memory-reviewer
  • all model manifests, blobs, and Modelfiles required to reproduce their exact state

Do not assume the original Hugging Face or Ollama downloads will still exist in the future. Prefer the preserved binary/model stores.

Important safety rules

  • Do not run restic init against the existing repository.
  • Do not run restic prune during initial disaster recovery.
  • Do not delete or overwrite Google Drive repository data.
  • Restore into temporary directories first.
  • Inspect and validate before replacing recovered data.
  • Do not expose KeePass secrets, OAuth client secrets, rclone tokens, or the Restic password publicly.
